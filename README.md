**好奇猴快传**是一款轻量、自托管、无需安装客户端的网页传输工具。同一套服务包含两种互不干扰的使用方式：

- **私人快传（默认首页）**：在自己的电脑、手机等设备间输入一次配对码，之后打开网页即可查看最新的文字、图片或文件。
- **公开分享**：为同事、朋友生成短取件码、分享链接或二维码，对方无需配对即可领取。

所有用户都可以把这套程序部署到**自己的服务器和域名**。GitHub 仓库只包含源代码与静态资源，不包含站长的 DNS、反向代理配置、配对关系或已上传文件。

## ✨ 功能一览

| 私人快传 | 公开分享 |
| --- | --- |
| 首次使用创建配对空间，其他设备通过配对码加入 | 无需注册或登录，直接寄文件/取文件 |
| 设备长期保持配对，重新打开网页自动识别（取决于浏览器 Cookie） | 4 位字母数字取件码、随机分享链接和二维码 |
| **双向互传**文字、图片、单个或多个文件 | 文件与文字可组合分享；支持整个文件夹打包 ZIP |
| **拖拽文件**到发送区；可逐个移除或清空待发送列表 | 可设置 1/3/7 天后过期，默认 3 天 |
| 网页打开时自动检查最新内容，文字一键复制、文件下载 | 每个取件码默认最多领取 10 次 |
| 一个私人空间**只保留最新一条**，成功发送新内容后替换旧内容 | 最近发送历史仅保存在当前浏览器 |
| 设备管理：直接显示/复制配对码、改名、解绑设备 | 适用于临时分享给未配对的人 |

私人快传默认单个空间最多绑定 **8 台设备**。网页保持打开时约每 6 秒检查一次内容更新；其他设备即使暂时离线，之后打开网页也可以获取当前最新内容。**私人快传不保存历史消息**，也不会自动读取系统剪贴板；发送和复制均由用户主动操作。

公开分享支持至多 **500 个文件/次**、单次总大小最多 **5 GiB**（需要代理与磁盘允许）。默认总存储配额为 **10 GiB**（公开分享与私人快传合计）。普通访客按 IP 每滚动 24 小时最多公开上传 **1 GiB**；额度不足时，站长可凭实例私有的上传口令解锁继续上传。公开领取与私人配对传输不受此访客日限额影响。

## 🚀 5 分钟部署（Docker Compose）

需要：一台安装 Docker / Docker Compose 的 Linux 服务器；推荐另备一个指向这台服务器的域名和 HTTPS 反向代理。

```bash
git clone https://github.com/xiaohouzidoudou/hamoki-transfer.git
cd hamoki-transfer

cp .env.example .env
# 用编辑器修改 .env 内的 PUBLIC_URL 为你自己的 HTTPS 域名

mkdir -p data upload-tmp
sudo chown 10001:10001 data upload-tmp

docker compose up -d --build
docker compose ps
```

默认容器仅监听服务器本机 **127.0.0.1:8018**，**不会自动开放一个公网网站**。请通过自己的 Nginx、Caddy、1Panel 等将 HTTPS 域名反向代理到 `http://127.0.0.1:8018`，并为域名配置 DNS 解析与有效证书。

例如编辑 `.env`（不要把它提交到 GitHub）：

```dotenv
PUBLIC_URL=https://send.example.com
MAX_UPLOAD_MB=5120
TOTAL_LIMIT_MB=10240
GUEST_DAILY_MB=1024
# UPLOAD_UNLOCK_PASSWORD 请只在你自己的 .env 中设置，绝不要写入 GitHub
```

然后在浏览器打开你的 `https://send.example.com`。**仅修改 `PUBLIC_URL` 并不会替你创建 DNS、证书和代理规则。** 如果 8018 端口已被占用，修改 `compose.yaml` 左侧绑定端口，并同步调整反向代理目标地址。

完整流程与代理配置示例见：**[独立部署指南](docs/DEPLOYMENT.md)**。

## 📱 怎么使用？

### 私人快传

1. 在第一台设备打开网站，点击**「创建我的配对空间」**。
2. 在「设备管理」里直接查看并复制当前配对码。
3. 用第二台设备访问**相同的网站域名**，输入配对码完成绑定；其他设备按相同步骤加入。
4. 在任一设备粘贴文字、选择文件或把文件拖进发送区域，然后点击「发送」。
5. 在另一台设备的网页上复制最新文字或下载最新文件。

设备管理支持修改设备名称与解绑。如果浏览器数据被清理、设备被解绑或者换了浏览器，需要重新配对。配对码应只分享给信任的设备使用。

### 公开分享

1. 切换到「寄文件」，上传文件、文件夹或文字。
2. 获取 4 位取件码、分享链接或二维码。
3. 对方在「取文件」输入取件码，或直接打开分享链接领取。

公开分享不要求对方加入你的私人配对空间。普通访客公开上传累计超过 1 GiB / 滚动24小时后，会看到口令验证界面；口令验证后该浏览器在 24 小时内可继续上传，但仍受单次上传限制和服务器剩余容量约束。

## 📊 简单访问日志

站长可点击网站页脚的**「访问日志」**，输入与公开上传解锁相同的私有口令查看每天的访问记录。按日期显示 IP、已绑定设备名称（若有）、访问/发送/领取操作和 HTTP 状态码；失败请求会突出显示，便于发现频繁尝试和异常访问。

- 日志保存在本机 `data/index.sqlite3`，默认保留约 30 天（同时有记录数量上限）。
- 日志不记录上传文字、文件内容、完整取件链接、配对码或上传口令。
- 登录会在当前浏览器保留 12 小时的受签名保护的会话。
- **日志仅供参考**：IP 可能是共享公网出口或代理，HTTP 失败记录不能直接证明遭到攻击。用作公网服务时请留意隐私告知和适用法律。

## ⚙️ 技术与数据

- **后端**：Python 3.12、Flask、Gunicorn、SQLite。
- **前端**：原生 HTML / CSS / JavaScript；保留浅色、深色主题。
- **运行**：Docker Compose；无需 Redis、对象存储或其他数据库。
- **持久化**：`./data` 保存数据库、公开分享文件、私人空间文件及配对密钥；`./upload-tmp` 用于上传过程中的临时文件。
- **配置**：见 [`.env.example`](.env.example)，不要把实际的 `.env`、`data/` 或私有备份上传到公开仓库。
- **健康检查**：`GET /health`，返回 `{"ok": true}`。

**备份恢复：** 请一起保存整个 `data/` 目录，尤其是 SQLite 数据库、上传的文件，以及配对码使用的隐藏密钥文件。仅重新下载 GitHub 源码**无法恢复原设备绑定、历史数据或原配对码**。参见 [备份/恢复说明](docs/DEPLOYMENT.md#备份与恢复)。

## 🔒 安全与使用限制

- **私人空间不是端到端加密**：服务器管理员可以访问服务器上保存的内容。请使用 HTTPS，保护配对码和服务器访问权限。
- 绑定设备的浏览器凭证由 Cookie 保存；清除浏览器数据、换浏览器或主动解绑后需要重新加入。配对关系不会因页面关闭而主动删除，但不是无法丢失的“永久登录”。
- **公开分享允许匿名上传**：未解锁访客按 IP 限制滚动 24 小时累计 1 GiB，换 IP、代理和共用公网 IP 可能影响识别。上传口令只放在自己的服务器环境中，绝不要硬编码公开仓库。请额外考虑反向代理限流和带宽消耗。
- 4 位取件码便于输入，但随机空间有限，不适合传输密码、密钥等高敏感资料。系统包含按 IP 的基础频率限制，不能替代生产级防滥用。
- 5 GiB 文件上传要求代理放宽请求体大小、上传缓冲与超时限制，并预留足够的磁盘空间。
- 这是一套单实例、轻量自托管应用；如用于大规模公开运营，请另外评估鉴权、防滥用、备份与监控方案。

## 🧑‍💻 本地开发与测试

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt pytest
DATA_DIR=./data python -m flask --app app run --port 8000
python -m unittest discover -s tests -v
```

在 Windows 上请使用对应的虚拟环境激活命令；本地开发 HTTP 环境不等同于实际 HTTPS 配对 Cookie 的生产行为。
